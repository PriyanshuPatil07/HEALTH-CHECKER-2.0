# HEALTH-CHECKER-2.0
This project is developed only for learning purposes and is not a replacement for professional medical advice. The program takes symptom input from the user and provides suitable home remedy suggestions along with their benefits and necessary precautions. 
Health Checker (Python Mini Project)

This project is a simple health checker program developed using Python. 
It suggests basic home remedies for common day-to-day health problems such as fever, cough, cold, gas, loose motion and hypertension.

The program takes symptom input from the user and provides:
- suggested home remedy
- benefit of the remedy
- precaution to be followed
- estimated severity level using NumPy regression

Technologies Used:
Python
Pandas
NumPy

Concepts Used:
Arrays
Loops
If-else conditions
Dictionary functions
Dataset creation using Pandas
Regression logic using NumPy

Features of the Project:
Simple and user-friendly interface
Menu-driven symptom selection
Severity prediction logic
Health suggestions with precautions
Easy to understand program structure

Purpose of the Project:
The objective of this project is to understand basic data processing techniques using Python and apply programming concepts like loops, arrays, conditional statements and regression in a practical example.
